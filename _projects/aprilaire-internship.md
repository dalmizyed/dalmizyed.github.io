During my summer 2026 internship, I worked on product testing, failure investigation, and customer-facing tools across AprilAire’s damper and dehumidifier lines.

- Found the root cause of motor failures in zone dampers and generated a load profile to guide design improvements.
- Resolved a recurring quality issue in barometric dampers using airflow and static pressure tests on a five-ton furnace system, a laminar flow element (LFE), and ASHRAE lab ducts.
- Built a live angular displacement measurement tool with Hall effect sensors, improving testing speed and reliability.
- Redesigned the dehumidifier sizing map using calculated humidification load data from across the United States.
- Wrote a work instruction for damper warranty failure investigations to keep root-cause analysis consistent.
- Found that an oversimplified EPR (Extended Producer Responsibility) calculation could cause under- or over-reporting by up to 22%.
